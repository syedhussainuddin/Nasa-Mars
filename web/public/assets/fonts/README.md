# Barlow

Locally hosted Barlow regular (400), semibold (600), and bold (700), from the
Google Fonts distribution, version 13.

- Designer: Jeremy Tribby
- Project: https://github.com/jpt/barlow
- Distribution: https://fonts.google.com/specimen/Barlow
- License: SIL Open Font License 1.1, included in `OFL.txt`.

No font service requests are needed at runtime.
